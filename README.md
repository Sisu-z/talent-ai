# TalentsAI 工作知识库

本仓库专门用于 TalentsAI 平台相关工作的知识沉淀、跨设备协作和上下文恢复。

我们以用户的专业判断为核心，使用 AI 协助完成专家任务的资料理解、任务设计、参考答案制作、评分规则设计、模型结果评估、质量检查、交付准备和复盘沉淀。当前重点是金融与会计领域的 Excel 高阶任务设计与模型评测。

## 工作方式

1. 开始工作前先拉取 GitHub 最新修改并阅读 `AGENTS.md`。
2. 根据任务领域进入 `01-专业领域/` 阅读对应资料。
3. 遇到相似问题时查阅 `02-复盘/`；遇到瓶颈或卡点时查阅 `03-经验/`。
4. 完成任务后沉淀有价值的新知识，并更新 `TODO.md`。
5. 验证修改后提交并推送到 GitHub。

## 上下文文件

- `AGENTS.md`：AI 协作规则。
- `PROJECT_CONTEXT.md`：项目目标和长期背景。
- `DECISIONS.md`：关键决定及原因。
- `TODO.md`：当前状态和下一步。
- `01-专业领域/`：按专业方向组织的知识库。
- `02-复盘/`：问题、反馈、根因与解决方案。
- `03-经验/`：个人和参与者的可复用经验。

## 新开聊天

如果当前聊天已经关联到本仓库所在的本地项目，只需输入：

> 先同步当前仓库，并按 `AGENTS.md` 加载项目上下文。然后处理这个任务：……

Codex 会从仓库根目录自动发现 `AGENTS.md`，并按其中顺序读取背景、专业领域、复盘和经验资料。

如果是在没有关联本地文件夹的云端聊天中，需要先用正式的 GitHub 连接功能授权并选择私有仓库 `Sisu-z/talent-ai`。不要在聊天消息中粘贴密码、访问令牌或 SSH 私钥。
