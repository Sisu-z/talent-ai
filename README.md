# talent-ai

用于在 Windows、macOS 和 GitHub 之间协作的 Talent AI 项目工作区。

## 工作方式

1. 开始工作前先拉取 GitHub 的最新修改。
2. 完成一个清晰的工作单元后提交修改。
3. 更新 `TODO.md`、`DECISIONS.md` 或 `PROJECT_CONTEXT.md`，让后续对话能够恢复上下文。
4. 工作结束后将提交推送到 GitHub。

## 上下文文件

- `AGENTS.md`：AI 协作规则。
- `PROJECT_CONTEXT.md`：项目目标和长期背景。
- `DECISIONS.md`：关键决定及原因。
- `TODO.md`：当前状态和下一步。
