## 内容要求

每条专业资料应尽量写明：

- 主题与所属细分领域。
- 核心结论或方法。
- 可靠来源及链接。
- 适用条件和不适用边界。
- 最后核验日期。
- 可信度：一手权威来源、可靠二手来源、个人经验或待验证。

专业资料发生冲突时，以用户的明确要求、专业判断和最新可靠一手来源为准。
