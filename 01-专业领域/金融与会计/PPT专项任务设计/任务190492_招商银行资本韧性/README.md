## 业务问题

以招商银行2024年度报告中的集团合并公开数据为事实基础，模拟资产负债管理委员会专题汇报：在净息差承压、核心收入收缩和零售风险上迁的背景下，2025年8%贷款增长计划能否通过产品组合重配，在集中度附加和参数不确定性下守住11.50%的内部CET1管理底线，并触发哪些固定行动。

题目以完整、可核验的ALCO决策链形成难度：

1. 复算盈利质量、息差量价和风险迁徙；
2. 用统一65% RWA密度完成中度、重度静态压力诊断；
3. 按“业务约束→资本底线→税后资本贡献”筛选四个8%候选组合；
4. 按A03分段集中度附加，在七产品全域求连续理论最优 `P^cont` 与0.5个百分点名义网格最优 `P^nom`；
5. 复算未采用A03时的旧网格，验证加入集中度附加后失守并必须重优化；
6. 在 `Gamma=0/1/2/3` 下分别重新优化，以 `Gamma=2` 网格最优作为 `P^rob`，完成两条鲁棒资本路径勾稽；
7. 用未舍入值为P0和P^rob匹配固定F/A/C代码、行动、责任部门与时限。
