# 二、Rubrics（考点）

![](https://oss-preview.talents-ai.com/uploads%2F1786433909790_TWVkYp.png?response-content-disposition=inline%3B%20filename%3D%221786433909790_TWVkYp.png%22&OSSAccessKeyId=LTAI5t5Yxnc7n2JXELEL1ikG&Expires=1789032123&Signature=ftk6YqKeRvAfv9Tvi4unnItfyzQ%3D)

  

为什么要用Rubrics （考点）来衡量模型回答质量？

PPT 修改任务通常包含多项要求，模型可能只完成其中一部分，因此不适合简单用“做对了”或“没做对”来评价。若只依赖人工整体打分，也容易受个人理解和审美影响，导致评分结果不稳定。

可以把 Rubrics 理解为一份**验收清单**。它把 Prompt 中的要求拆成具体评分项，告诉评分者：检查哪一页、哪个对象、达到什么标准算完成、完成后可以得多少分。

Rubrics 还能通过不同权重体现要求的重要程度，更符合实际使用感受。

### 2.1.3 具体规则写法标准

小tips：

**1.Rubrics 要与题目一致，但要写得更具体直接。**

Rubrics 不能改变或增加题目要求，而要把要求转换成可直接核对的页码、对象和完成标准，让评分者一眼就知道检查什么。示例：

> 题目：ppt除了章节页和标题页外，其他页面的页脚都改成2025-9-10（相对模糊，没有点名哪些页面）

> rubrics：第2～4，6～10，12～15页的页脚都是2025-9-10（精准点名具体页数）

**2.不能依赖出题人解释才能判断，不要让评分者猜。**

如果评分者还需要判断“具体指哪些页”“做到什么程度才算完成”，说明这条 Rubric 不够清楚，需要重写。

|   |   |   |
|---|---|---|
|**要求点**|**解释**|**示例**|
