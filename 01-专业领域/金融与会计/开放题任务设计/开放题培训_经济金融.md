#### 题目内容要求

学习材料

## 一、通用质量原则

**场景真实**：任务应来自真实职业工作场景，避免虚构感过强或模板化套壳。

**输入充分**：模型完成任务所需资料应在任务描述或附件中提供。

**输出收敛**：不同模型或同一模型多次作答时，核心答案应基本一致。

**可客观判分**：任务描述中提出的要求应能被 Rubrics 拆解为明确考点。

**专业匹配**：题目应与出题人的领域背景和职业经验一致。

**形态一致**：任务描述、参考答案、平台选择的输出类型和 Rubrics 应保持一致。



## 二、场景设定：谁在什么情况下需要这份输出

场景设定需用一两句话把背景讲清楚，包括：什么职位的人、遇到了什么事、为什么需要产出这份文本或文档。场景不必冗长，但必须具体。

## 三、 题目内容：输出必须满足哪些具体标准

任务描述需要写清楚模型应完成的具体事项。核心原则是：每一条要求都应让读者能明确判断“做到了”或“没做到”。

- 需要**明确**要求模型输出什么类型的答案（“请输出文本答案”，“请输出word格式文件”，“请输出Pdf格式文件”等等）
- 纯文本题应明确文本可从正文直接判断的明确要求，不过于开放或含糊，优秀回答不是发散的。
- Word 题应涉及文件类型、文件名及字体、字号、行距、图表、目录、页眉页脚等格式要求。（不强制所有都必须有，是基于当前题目在工作场景中所涉及的格式相关内容，不宜过多3-6条即可）
- PDF 题应写清文件类型、文件名及最终成品上可见的版式、分页、表格、标红 / 加粗等要求。

## 四、 时效性内容必须锚定时间

如果题目涉及会随时间变化的信息，例如股价、汇率、政策法规、热点事件、行业排名、财报数据等，必须在题目中明确标注时间点，否则同一道题在不同时间作答会出现答案不一致，无法判分。

- Bad：“目前A股中最值得投资的行业是什么？” (答案随时间变化)
- Good：“在2025年第三季度，A股申万一级行业指数中回报率最高的指数是哪个？”(答案不变)

## 五、 避免模板套路化

同一类任务在不同行业、不同场景下，真实要求通常差异很大。题目不能只替换行业、角色和格式要求，形成批量模板。行业差异应体现在任务流程、数据来源、判断依据、输出规范和避坑要点上。

同一领域内也不能用高度相似的骨架重复出题，也属于训练价值较低的重复题。

## 六、 题目需客观、收敛、可判分

任务描述应做到客观、收敛、可判分。如果题目过于开放，不同模型每次给出的内容都不一样，Rubrics 无法收敛，无法客观判分。

- 优先将题目所需材料作为附件提供。
- 确需联网搜索时，必须限定数据来源、检索范围和提取目标。
- 网络上不可获取或不可稳定获取的材料，必须做成附件。
- 存在多种口径 / 算法的指标，必须在 Prompt 中提前锁定口径。
- 不得在 Prompt 未写明口径的情况下，在 Rubrics 中暗中按某一口径扣分。
- Bad：“请写一篇腾讯控股的研究报告，分析其投资机会。” (太开放了)
- Good：“请基于腾讯截止到2025年第三季度的财报和已公开的行业数据，撰写一份研究报告，重点评估其视频号业务当前的业务规模、商业化成熟度及生态影响：视频号的DAU、TUA分别是多少？与2024年Q3相比，这些核心数据实现了怎样的增长？这些数据与抖音、快手截止到2025Q3数据相比，处于什么位置？” (要求具体)

## 七、 输出篇幅控制

模型输出不应过长。纯文本题建议以输出内容为准；Word 或 PDF 题输出不应超过 20 页。建议在任务中明确各章节字数或长度，例如“业绩概览 300–500 字”。如内容确需深度展开，建议拆成多道独立题目。

#### 参考答案通用要求

学习材料

## 基本要求

**参考答案是出题人心目中的“满分回答”。**在当前题目下，模型应交付什么，出题人就应亲手撰写或制作一份对应形态的标准答案

参考答案需要与题目要求输出一致

- 如题目要求输出pdf，则需要上传.pdf文件
- 如题目除了pdf文件外还需要输出一段话，可以同时选择文字+pdf文件
- 参考答案必须由出题人亲手撰写，严禁直接使用 AI 生成内容或照搬模型回复后稍作修改

##

## 思考过程要求

在正式写参考答案之前，先用几段话（200–300 字左右）说说你动笔前在脑子里过了什么——就像跟同事解释"我为什么这么做"一样，重点说清楚以下四件事：

**这道题难在哪？**不只是复述题目要求，而是说出作为行内人，你觉得这道题最容易出错、或最需要专业经验才能做对的地方在哪里

**有哪些"默认规矩"是外行不知道的？**题目里没写出来，但你实际做这件事时必须考虑的行业惯例、格式规范或监管要求。比如：这类合同审查一定要先查某条款；这类报告的数据口径行业里有统一标准，不能随意选

**题目信息不够用，你怎么处理？**说明有没有信息题目没提供但你用到了，以及你做了什么合理假设。比如：题目没给汇率，我默认用题目日期当天的官方汇率

**哪些结论你有把握，哪些是推断？**如果某个结论在现实中还需要进一步核实，直接说出来。敢说"这部分我不确定"反而说明你思考认真

## 一、Rubrics 的定义

Rubrics 就是标准答案的一组考点。相当于主观题批改时的“踩点给分表”。出题人需要把每道题的满分答案拆解成具体、客观、可复核的评分点，让不同评分者依据同一套标准能得到相近结果。



## 二、数量与分值要求

|   |   |
|---|---|
|**项目**|**要求**|
|总条数|≥25 条，建议 25-50 条|
|负分项数量|≥2条|
|标签类型|≥3类|
|正分总分|50–200 分|
|正负分项比例|正分项数量≥2倍负分项数量|



## 三、考点类别

|   |   |
|---|---|
|**Rubric 标签**|**考的是什么**|
|文件管理 / 操作|文件创建、命名、保存格式等|
|事实信息|专业内容、客观事实类型的信息等内容|
|观点分析|专业判断、观点性的考点，分析|
|指令遵循|是否严格按 Prompt 要求执行|
|行文/文档结构|文档基础格式、章节层级、目录、分节合理性，存在冗余等|
|跨文档一致性|输出与输入参考文件数据、模板、条款或证据匹配等是否一致|
|专业/格式规范|行业术语、行业标准、法规 / 准则 / 业务规范等|
|其他|以上不覆盖的|

##

## 四、正分项、负分项与致命项

正分项用于评价 Prompt 明确要求模型做到的内容或格式

负分项用于惩罚模型主动产生的错误、幻觉、违规或严重格式问题，不能用来反向惩罚模型回答正确的部分

同一内容不能既设置正分项，又设置负分项重复计分

同一个内容错误不能换角度重复扣分

致命项用于未按指定形态输出、文件无法打开、PDF 全文乱码不可读等红线问题。（致命项必须是负分项，适用于word/PDF格式，统一标注 -10 分；一道题一般不超过 2 个致命项）

|   |   |   |
|---|---|---|
|**分值类型**|**适用场景**|**示例**|
|+1～+3 低权重|基础格式、回答加分项|格式上对应标题居中、正确加粗相应字段等；<br><br>内容上对应依据题目发散的，用于展现回答深度和广度的拓展信息等|
|+4～+6 中权重|内容完整性|格式上章节齐全，内容上重要信息完整等|
|+7～+10 高权重|核心内容正确性|关键数值计算正确、关键论点准确、核心结论到位等|
|-1~-3 轻微错误|细节偏差|字数稍超、字体偏小一号，或非关键信息瑕疵错误等|
|-4~-6 中等错误|格式错误、信息缺失|格式上章节层级混乱，内容上关键信息缺失等|

## 二元判分

每条 Rubric 只有两种结果：命中 / 未命中，不存在部分命中得部分的分数。写 Rubric 时必须确保每条规则可被二元判断。

## 扣分项判断

扣分项的表述应直接描述错误是什么。“命中”的含义是模型犯了这个错误，命中即扣分；未命中则不扣分。

## 最终得分计算

最终得分 =（正分项命中总分 − 负分项命中总扣分）/ 正分项满分。分母只计算正分项满分，不包括扣分项。
