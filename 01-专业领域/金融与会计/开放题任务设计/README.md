# 经济金融开放题任务设计

本目录保存 TalentsAI 经济金融开放题相关的培训资料、题目设计规范和后续任务记录。

## 阅读顺序

1. 先读 [`开放题培训_经济金融.md`](开放题培训_经济金融.md)，确认支持的输出形态和通用质量原则。
2. 设计题目时重点复核：真实场景、输入充分、输出收敛、客观判分、时效锚定和输出形态一致。
3. 制作参考答案时重点复核：满分完整性、业内思考过程、证据与计算链，以及 Word/PDF 的打开和版式检查。
4. 编写 Rubrics 时再核对数量、分值、原子化、来源定位、二元判分和正负项不重复。
