# 经验

本目录保存用户本人、其他参与者或可靠公开来源总结的可复用技巧、判断方法和工作流。

## 什么时候查阅

- 遇到瓶颈、卡点或不知道下一步如何推进时。
- 希望提高效率、质量或通过率时。
- 需要选择工作方法、工具或检查策略时。

先在 [索引](索引.md) 中按任务类型、问题场景和关键词查找。经验只能在适用条件匹配时使用，不能替代用户的专业判断或经过核验的专业事实。

## 记录要求

- 使用 [经验模板](经验模板.md)。
- 区分本人经验、匿名参与者经验和公开来源经验。
- 其他参与者默认匿名化，不记录未经允许的姓名、账号或联系方式。
- 写明适用条件、限制、验证情况和可能失效的原因。
- 文件名建议为 `领域-主题简述.md`。
